# Jeevan Biju Korah: portfolio

Personal site: projects, case studies, experience and a scrapbook. Built with Next.js (App Router) and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All text, links, projects, timeline and scrapbook entries live in [`lib/data.ts`](lib/data.ts).
Images are in `public/`. The résumé served at `/resume.pdf` is `public/resume.pdf`.

## Deploy

Deployed on Vercel. Every push to `main` redeploys the site.
